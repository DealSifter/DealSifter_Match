consensus/usability, supporting/conflicting observations, outliers, source freshness,
resolution basis and qualification. Observed values/ranges only, no manufactured scalar.
Publisher and current user's existing clarifications are one source family. Existing
authorized RentCast cache fields are another; license-approved already-acquired GIS is
handed off as a signed actor/coordinate-bound receipt and revalidated locally.

No live GIS or RentCast acquisition is added to Maxxis. No new table/cache column,
property/profile/listing writes, feature framework, secret, price or source. Missing
public evidence means none available in this context, not an assertion of no record.

sanitized property RPC authorization, current subject and paid-cache entitlement remain.

and evidence/conflict inspection run before stale pending financing gaps, report context
and Gemini. Tool output is formatted deterministically and never forwarded to Gemini
for factual arbitration. Public factual GIS does not require asset unlock or Nuggets.
