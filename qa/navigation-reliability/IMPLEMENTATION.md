# Navigation reliability and parcel capability lifecycle

Confirmed production defect: two retained release asset URLs (`MapView-CYCaaVUC.js` and `ParcelLensLayer-XRoS49Vs.js`) returned HTTP 200 / text/html, not JavaScript, from the SPA catch-all after deployment. Missing `/assets/` requests must not become an immutable-cache HTML success. The routing rewrite now excludes `/assets/`; all non-asset HTML/deep-link responses are explicitly no-store while existing real content-hashed assets remain immutable. References: https://vercel.com/docs/project-configuration/vercel-json#negative-lookahead and https://vite.dev/guide/build#load-error-handling.

Additional confirmed code defects: the old module loader attempted only one import and automatically reloaded the whole app on recognized transport errors; all other errors were mislabeled as old cache. Nested optional parcel layers used unguarded React.lazy under MapView without a local page boundary. The retained-page branch returned early for Map/Plans/Settings, unmounting Feed/Matches/Onboarding. A failed initial feature-flag request permanently hid the magnifier until the next login/reload; no online/foreground recovery existed. Popup availability additionally reparsed narrow payload lat/lng/id fields rather than using the selected canonical inventory point/ID.

Retained pages persist across other modules with hidden Activity effect cleanup, scoped to the authenticated owner; logout/account changes remove previous state. The canonical pre-offset PIN inventory drives parcel selection, not display offsets or mixed payload aliases; privacy/point changes cancel stale parcel context. Flag request lifecycle has bounded recovery and foreground/online checks, immediately denies cross-account cached grants, preserves an existing confirmed same-account grant only while checking, and honors explicit server denial/revocation. Backend authorization remains authoritative. Popup status now distinguishes pending, unavailable with retry, and explicit account denial, rather than silently hiding the missing capability.
