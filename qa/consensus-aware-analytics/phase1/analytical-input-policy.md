# Physical analytical inputs — phase 1

Consensus, effective user decisions and analytical permission are separate layers. A choice never rewrites the underlying evidence consensus. The pure resolver performs no acquisition, database write, network call or language-model arbitration.

| Permission | Allowed input |
| --- | --- |
| ALLOW_CONFIRMED | Consistent, observed scalar |
| ALLOW_QUALIFIED | Legitimate single-source/publisher scalar, or explicit current KEEP/ACCEPT decision |
| ALLOW_RANGE | Positive observed agreement range with at least two independent source families |
| BLOCK_CONFLICT | Unresolved material disagreement, deferred conflict, incompatible effective/projected scalar |
| BLOCK_UNAVAILABLE | Missing, invalid, unsafe, expired or unauthorized evidence; unavailable decision proof |
| NOT_APPLICABLE | Living/building metric on vacant land or explicit domain non-applicability |

Areas normalize to square feet with exactly 43,560 sqft per acre. Engine arithmetic retains precision. UI formatting alone rounds results. Price/area ranges invert endpoints; no midpoint is introduced. A nonpositive or missing denominator never becomes zero, NaN or Infinity.

LOT_AREA and LIVING_AREA/BUILDING_AREA are distinct domains. The existing reviewed buildingArea field supplies the building/living alias, never the parcel area. Current property `price` supplies asking-price metrics; assessment, AVM and comp prices are not fallbacks. Proposed building size and unit count remain explicit user assumptions. Zoning codes do not infer capacity, density or allowed use.

Owner review snapshots remain behind existing owner authorization. Other readers obtain effective facts through the existing sanitized published-property RPC. A bounded additional read selects only the current publisher's two physical-area decision proofs, matches public effective facts and strips reviewer/history/private alternatives. Read failure blocks analytics. No schema, RLS or flag changes are required.

That additional decision-proof read is explicitly enabled only for area-analysis requests. Existing APN/zoning/direct-fact reads gain no additional database query. An existing cache-only READ fallback may serve a notification opened before owner-batch hydration; it is not a provider acquisition, CHECK or mutation.

Existing report/financial consumers retain legacy default contracts. Only live analytical paths explicitly opt into the new policy. Acquisition-plus-rehab, stored cap rate, NOI, ROI, CoC, DSCR, ARV, MAO and recent-sales methodology are not migrated. Existing LAND area-dependent unit calculations can carry a qualified scalar or observed range; financial formulas are unchanged.

The modal CTA changes only local page state. Portfolio warnings remain conflict-only. Radio selection does not mutate the network; one existing DECIDE batch applies choices. Reduced-motion removes the opacity pulse. Direct price/area questions bypass stale gap/local scenario interception and resolve through the authorized cache-only deterministic backend route before Gemini.
