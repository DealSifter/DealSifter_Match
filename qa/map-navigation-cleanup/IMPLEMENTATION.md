# MapView exit crash — selection camera lifecycle

The incident was reproduced with real React 19 / React-Leaflet / Leaflet on desktop and phone, using explicit synthetic property data and mock authentication. Idle map exit succeeded; selecting a PIN and then removing MapView triggered `Cannot read properties of undefined (reading '_leaflet_pos')`.

The captured stack points to `MapSelectionCamera.cancel -> Leaflet.stop -> setZoom -> getCenter -> _getMapPanePos`. React-Leaflet's parent MapContainer cleanup calls `map.remove()` before the child camera's passive cleanup. Leaflet remove already stops animations and deletes the map pane. The old child cleanup then called stop on the destroyed instance. The exception during removal escaped the outgoing module into the application error boundary.

The camera now observes the existing public Leaflet unload event. A removed camera never calls stop or focus. Explicit idempotent disposal cancels live movement only, detaches its unload listener, and suppresses subsequent commands. The React effect still cancels its animation frame and now disposes the camera. No exception swallowing, automatic document reload, private Leaflet pane access or global prototype patch is introduced into application code.

An expanded check with the parcel lens enabled subsequently reproduced a second, asynchronous failure: Leaflet 1.9.4's untracked 250ms CSS-zoom completion callback invoked `_move` after removal. The captured native stack is retained in expanded-stack.json; expanded-first.json retains the first additional failure. The application now installs a map-wide unload observer in a narrowly scoped Leaflet compatibility adapter. On unload it clears the native animation-in-progress bit so the already queued completion returns immediately. It does not disable live animations or patch prototypes. ResizeObserver work is also coalesced to one pending frame and canceled on effect cleanup.

Evidence: before.json retains the original failing stacks; after.json checks idle, selected PIN, in-flight selection, fractional zoom, active parcel lens and in-progress native zoom on both devices. Camera tests include parent-first removal and early frame cancellation. The 78-test affected closure includes module retry, parcel lens and native animation teardown regressions. Contract TypeScript and scoped lint passed. Production build uses the committed baseline plus only the camera and map lifetime files, excluding the unfinished property-enrichment changes in the shared workspace.
