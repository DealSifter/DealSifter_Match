# Public dataset ingestion: design only; no migration/ingestion applied

Identified: Florida DOR/FGIO distributions (live runtime blocked), Ohio OGRIP public polygon export (live runtime blocked), TxGIO StratMap shapefile/geodatabase (hosted-use clearance pending), LA assessor file-geodatabase/shapefile (terms review pending), PASDA incomplete aggregation (county/ID review pending). Downloadability is not public-display approval. No bulk files were downloaded and no restricted/paid provider was used.

The existing parcel cache is isolate memory only (128 entries / 16 MB, 24-hour fresh + 7-day stale maximum); it cannot spatially index or persist nationwide polygons. Existing evidence/property tables are not an authorized canonical parcel spatial store. Accordingly, no giant ingestion framework, persistent schema, cron job or new infrastructure is introduced. Migration = NONE. Any actual ingestion is STOPPED before a new persistent spatial migration.

Proposed future isolated public schema: source/version manifest; parcel_public(source_id, source_record_id, county_fips, geometry MultiPolygon SRID 4326, public_attributes JSONB, source_updated_at, retrieved_at, permitted-use status). No user IDs, notes, contacts, unlock state or financial assumptions. Unique (source_id, source_record_id); GiST geometry and btree county/source-version. Normalize independent reported assessor/GIS area and calculated area, with provenance; do not replace CanonicalPropertyFacts.

Refresh: offline staged import per approved authority vintage; validate license, FIPS, nonempty geometry, units and coverage before atomic version swap; retain a bounded prior version for source-specific rollback. Never load full snapshots during an interactive HTTP request. Expected storage and cost = NOT_MEASURED (no representative bulk downloads/row benchmarks were performed). Size must be measured from approved sample files before a migration is requested. Risks: multi-million polygon volume, indexes, authority vintage drift, restrictions changing, partial replacement and stale versions. No purchase or external coordination authorized.

GA adds only shared upstream rate-limit counters using the existing atomic RPC/table, with its existing short-lived cleanup. No new table or service; incremental infrastructure cost has not been benchmarked. Per-origin quota is 40 public GIS HTTP calls/minute across isolates/users, in addition to existing per-user and isolate courtesy/backoff limits. Cache hits/coalesced requests avoid additional source HTTP calls.
